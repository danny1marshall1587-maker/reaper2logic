How REAPER to Logic Pro conversion works

This tool parses REAPER project structure into an Apple-compatible Final Cut Pro XML (.fcpxml). In Logic Pro, simply navigate to File > Import > Final Cut Pro XML... to automatically recreate all tracks, items, alignment, sample offsets, gain, tempo maps, and markers!

Logic Pro

Importing into Logic Pro

  1. Download the generated .fcpxml file.
  2. Launch Logic Pro on macOS.
  3. Go to File > Import > Final Cut Pro XML...
  4. Choose the downloaded .fcpxml file.
  5. Logic Pro will automatically reconstruct your tracks, audio clips, timeline placement, volume, and markers!
REAPER

Importing into REAPER

  1. Download the generated .rpp file.
  2. Launch REAPER.
  3. Go to File > Open Project... or double-click the .rpp file.
  4. If prompted for audio files, select your project media folder.
  5. All tracks, items, fades, pan, volume, and tempo map will load into REAPER.
